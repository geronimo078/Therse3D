# therse3d — AI-Native WebGPU 3D Engine

> **Project Goal:** A high-performance, data-oriented WebGPU 3D engine in TypeScript that is as easy to use as Three.js, yet optimized from the ground up for **AI code generation (LLMs)**, **AI agents (MCP/tool-use)**, and **Vision-Language Models (VLMs)**.

For the complete master specification and 6-step implementation plan, see [Architecture.md](Architecture.md) and [AI_DEV_GUIDE.md](AI_DEV_GUIDE.md).
